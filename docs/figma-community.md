## Description

Color Catcher is a focused color utility for Figma. Select any layer with a solid fill and get the color in multiple formats, plus an intelligent human readable name that you can copy with one click.

### Features

* Instant extraction from the current selection
* Formats: HEX, RGB, HSL, CSS, OKLCH
* Smart color naming from a 1,566 color database
* Click to copy for every value, including the name
* Drag to reorder format rows
* Persisted format order across sessions
* Reset control when the order differs from the default
* Lightweight UI with real time updates

### How to use

1. Run the plugin
2. Select a layer with a solid fill
3. Click any row to copy
4. Drag rows to reorder if desired

### Notes

OKLCH is a perceptually uniform color space that is increasingly used in modern CSS and design systems.
